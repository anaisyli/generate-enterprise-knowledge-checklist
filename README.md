# 企业知识库资料清单生成 Skill

根据企业官网，为海外外贸 SEO 客户生成可填写的行业知识库资料收集清单。输出 Word，不是已经填好的知识库，也不保证读到官网的每一页。

## 位置与使用

将此 Skill 文件夹作为一个整体注册到使用的工具；注册/安装路径因 Codex、Copilot 或其他支持 Skill 的工具不同而异。仅把文件夹放在某个位置，并不代表所有工具都会自动发现，具体按对应工具的 Skill 配置方式操作。

安装后可以说：

> 根据官网〈客户官网地址〉生成企业知识库资料清单。

也可以同时提供产品分类截图、产品目录或参考文档。目录仅按用户截图/明确指定或官网明确展示的分类与顺序生成；官网只有平铺产品、分类不确定时先确认，禁止自行分组、重排、拆分或扩展。保留官网产品英文原名，不擅自改成产品定位或营销名称。官网或截图不能读取时，需补充资料。

清单用于 SEO/GEO 公开知识库，默认不收集股权/注册资本、营业额、在手订单、客户及渠道占比、内部报价/付款/合同计价、内部技术机密等。确有必要的资料只可选收集，须脱敏并取得客户明确的公开授权；案例客户名和现场资料须授权或脱敏。禁止索取密码、密钥等秘密信息；内部文件也仅提供符合上述边界的必要摘录。

## 工作流程

1. 读取官网公开信息，判断行业、主营业务和中英文产品目录，记录来源和未读取部分。
2. 按体外诊断参考模板生成七章，替换为对应行业的资料收集要求；固定保留 3.1 ODM/OEM 解决方案、3.2 行业解决方案，不擅加 1.4、3.3/3.4、4.3/4.4 等同级章节。
3. 只展开第一产品大类的前五个实际小类，每个小类包含产品概述、特性、应用场景和规格参数；其余大类只保留标题和蓝色提示。
4. 检查行业适配、英文、专业知识、编号、目录和蓝字，修订后导出 Word。

蓝字不省略：保留英文资料优先的提示；第一个大类和其他每个大类的补充提示；行业趋势部分可提供已有资料的提示。文案做了更适合客户阅读的调整，Word 中仍为蓝色。产品补充提示是邀请客户补充，不表示 Skill 自动展开更多产品。

输出不含表格和具体公司名称，标题及资料要点带英文，型号保留原名。目标约 6000 字，结合模板各板块篇幅和实际小类数量调整，不靠虚构内容凑字。需要人或 AI 检查行业准确性：脚本不能替代专业审核。

## 文件

- `SKILL.md`：触发条件和执行流程。
- `references\workflow.md`：模板规则、蓝字、审核及稿件格式。
- `assets\templates\`：五份去除具体产品型号和文档作者信息的行业参考模板；体外诊断模板是默认主参考。
- `scripts\render_checklist.py`：校验结构、输出无表格 Word，保留蓝字。
- `tests\test_render_checklist.py`：生成器的结构与导出测试。

## 使用生成器

需要 Python 3.9 及以上，不依赖第三方 Python 包。AI 应先根据 `references\workflow.md` 创建完整 UTF-8 JSON 稿件，审核后在 Skill 目录运行：

```powershell
python scripts\render_checklist.py ".\稿件.json" ".\行业知识库清单.docx"
```

脚本发现结构不合规会报错、不创建 Word；输出文件已存在时不会覆盖。运行成功只代表程序检查通过，不代表事实、翻译和公司名已被验证。仅本地生成 Word；脚本不会抓取官网。阅读官网需要使用运行 Skill 的 AI 工具自身的网络/浏览器能力。

命令中的相对路径以当前工作目录为准；请在放有稿件的工作目录执行，并根据需要调整脚本的相对位置。

本 Skill 的示例不使用真实客户、项目或官网；实际运行时提供的网址和客户资料仅用于对应任务，不应写入公开的 Skill 示例或仓库。

运行自测：

```powershell
python -m unittest discover -s tests -v
```
